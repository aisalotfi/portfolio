Project Overview

وب‌سایت رسمی کارخانه سنگ صدف استون یک پروژه واقعی برای یک شرکت فعال در صنعت سنگ ساختمانی است. این وبسایت با هدف نمایش محصولات و خدمات شرکت طراحی و پیاده‌سازی شد.

Problem

شرکت فاقد یک وبسایت حرفه‌ای برای نمایش محصولات و ارتباط با مشتریان بود. وبسایت قبلی قدیمی، غیرواکنش‌گرا و از نظر ظاهری نامناسب بود.

Solution

یک وبسایت مدرن با Next.js و Tailwind CSS طراحی و پیاده‌سازی شد. تمرکز روی سرعت، واکنش‌گرایی و نمایش حرفه‌ای محصولات بود.

Responsibilities

  • طراحی و پیاده‌سازی کامل رابط کاربری
  • معماری و توسعه فرانت‌اند با Next.js
  • بهینه‌سازی سرعت و سئو
  • استقرار روی Vercel

Tech Stack

Next.jsTypeScriptTailwind CSSVercel

Challenges

گالری محصولات

طراحی یک گالری تصویری مناسب برای نمایش محصولات سنگ که هم سریع بارگذاری شود و هم زیبا به نظر برسد.

واکنش‌گرایی

اطمینان از نمایش صحیح وبسایت روی همه دستگاه‌ها با توجه به تصاویر باکیفیت محصولات.

سئو

بهینه‌سازی وبسایت برای موتورهای جستجو با استفاده از قابلیت‌های SSRNext.js.

Outcome

وبسایت با موفقیت راه‌اندازی شد و بازخورد مثبت کارفرما را به همراه داشت. سرعت بارگذاری بالا و طراحی مدرن از نقاط قوت پروژه بودند.

Lessons Learned

  • تجربه کار روی یک پروژه واقعی از صفر تا صد
  • آشنایی عملی با چالش‌های استقرار و دامنه
  • اهمیت ارتباط با کارفرما برای شفاف‌سازی نیازها
  • مدیریت زمان و تحویل به‌موقع پروژه
